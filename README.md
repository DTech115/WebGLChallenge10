# WEBGLWeekly10

## Reflection
1. What object did you make interactive using raycasting?  
The collectable waffles around the map.
2. How does raycasting differ from collision detection?  
It uses what is essentially a laserrrr that, upon hitting whatever desired thing, can trigger a hit & be used for whatever you need. That way, you don't need your subject to literally be IN the bounding box of something to interact with it.
3. Why must a ray have both an origin and a direction?  
So that it can have a place to start at & a direction to go in [usually forward].
4. What sound effect did you choose and why?  
I chose footsteps for donkey's movement for immersion, a victory sound for eating a waffle, & an annoying voiceline for every waffle you eat to make it accurate. Also, music for Shrek's Toothless dance.
5. How did adding sound and interaction improve your scene?  
It made it MUCH more interesting & immersive, like you're actually there.
6. What additional interactive object would you add if you had another hour?
I'd add sound effects to everything, including the horses, people walking, & Shrek himself!
